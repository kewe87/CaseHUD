## CaseHUD 1.0.1

Fehlerbehebungen und Feinschliff für 1.0.
*Bug fixes and polish for 1.0. English below.*

### Änderungen
- **Autostart:** CaseHUD startet nach der Anmeldung wieder still im Tray. Ein zweiter Start mit `--minimized` öffnet kein Fenster mehr und leert nicht mehr das Log der laufenden Instanz; das Log nennt die Startparameter
- **Universal Screen 8.8" – Drehung:** Das Display dreht um 180° jetzt selbst (wie die Hersteller-Software), statt das Bild in Software zu spiegeln; 90° (hochkant, rechte Kante oben) nutzt dieselbe Gerätedrehung. Der Testschalter „Hardware-Drehung“ entfällt beim 8.8". Die Drehung wird bei jeder Verbindung einmal gesendet, damit eine von anderer Software verstellte Drehung korrigiert wird
- **Firmware-Version:** steht jetzt im Display-Drawer (8.8" als `V1.5`, Lüfter-LCDs als Version mit Datum); das 8.8" wird nach dem Verbinden zuverlässig abgefragt
- **Hell/Dunkel-Schalter** im Drawer springt nicht mehr zurück, während gespeichert wird
- **Geräte neu suchen:** Nur noch das Symbol dreht sich, und zwar genau so lange, wie die Suche läuft
- **Experimentelle Geräte** erscheinen in den Einstellungen nur noch im Expertenmodus (solange sie eingeschaltet sind, bleiben sie sichtbar)
- README: Beleuchtung auf der Entwickler-Hardware als getestet markiert
- CI: ein Test mit Windows-Pfaden läuft nur noch unter Windows

### Installation
`CaseHUD-Setup-1.0.1.exe` herunterladen und ausführen; eine bestehende Installation wird aktualisiert, Einstellungen bleiben erhalten. Alternativ gibt's eine portable ZIP. Hinweise zu dauerhaften Schreibvorgängen im Gerät und zum Haftungsausschluss: siehe Release Notes 1.0.0.

> ⚠️ Nutzung auf eigene Gefahr. CaseHUD ist ein privates Community-Projekt und steht in keiner Verbindung zu Lian Li.

### English

**Changes**
- **Autostart:** CaseHUD starts quietly in the tray again after sign-in. A second start with `--minimized` no longer opens a window and no longer empties the running instance's log; the log records the start arguments
- **Universal Screen 8.8" rotation:** the display now turns by 180 degrees itself (like the vendor software) instead of the picture being mirrored in software; 90 degrees (upright, right edge up) uses the same device turn. The "device-side rotation" test switch is gone for the 8.8". The rotation is sent once per connection, so a rotation changed by other software is corrected
- **Firmware version:** shown in the display drawer (8.8" as `V1.5`, fan LCDs as version with date); the 8.8" is queried reliably after connecting
- **Light/dark switch** in the drawer no longer snaps back while saving
- **Rescan devices:** only the icon turns, for exactly as long as the scan runs
- **Experimental devices** show up in the settings only in expert mode (they stay visible while switched on)
- README: lighting marked as tested on the developer's hardware
- CI: a test with Windows paths runs on Windows only

**Installation**
Download and run `CaseHUD-Setup-1.0.1.exe`; an existing installation is updated and keeps its settings. A portable ZIP is available too. For permanent device writes and the disclaimer see the 1.0.0 release notes.

> ⚠️ Use at your own risk. CaseHUD is a private community project and is not affiliated with Lian Li.
