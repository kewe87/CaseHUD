## CaseHUD 1.0.3

Licht-Presets, Startbild für den 8.8" und viele Korrekturen.
*Lighting presets, boot picture for the 8.8" and many fixes. English below.*

### Änderungen
- **Licht-Presets:** Fertige Kombinationen aus Effekt und Parametern kommen aus der Community-Library oder lassen sich selbst speichern und wieder anwenden. Auch über die API v1: `GET` und `POST /api/v1/lighting/presets`, `POST /api/v1/lighting/presets/{id}/apply`, `DELETE /api/v1/lighting/presets/{id}`; der Lichtstatus enthält das Feld `preset` (Details in `docs/API.md`)
- **Frische Installation ohne persönliche Voreinstellungen:** Es gibt keine eingebauten Presets und Vorlagen mehr, die zu einem bestimmten PC gehören. Neue Displays starten mit CPU-/GPU-Designs, die keinen Wasser- oder Pumpensensor brauchen. Bestehende Einstellungen bleiben unverändert
- **Startbild für den Universal Screen 8.8":** Das CaseHUD-Logo wird einmalig als Startbild ins Display geschrieben, gekoppelt an den Schalter für das Startbild (Einstellungen → Geräte). Der Haftungsausschluss (jetzt Version 3) muss einmal erneut bestätigt werden. Ein erzwungenes Neuschreiben überspringt ein unverändertes 8.8"-Startbild
- **Szenen** behalten die eigene Drehung des Displays
- **Oberfläche:** Der Wechsel zwischen Dunkel und Hell greift immer; Speichern für ein Display geschieht der Reihe nach (zwei schnelle Klicks konnten beim ersten Stand enden); alle Design-Arten haben jetzt Namen in der Oberfläche; kleinere Korrekturen
- **Robuster:** Fehler beim Schreiben des Startbilds und beim Laden der Preset-Datei werden sicherer behandelt
- **Qualität:** statische Analyse und weitere Prüfungen in der CI, aktualisierte Abhängigkeiten, gebaut mit Go 1.27.3

### Installation
`CaseHUD-Setup-1.0.3.exe` herunterladen und ausführen; eine bestehende Installation wird aktualisiert, Einstellungen bleiben erhalten. Alternativ gibt's eine portable ZIP; das Update direkt aus CaseHUD ist ebenfalls möglich. Hinweise zu dauerhaften Schreibvorgängen im Gerät und zum Haftungsausschluss: siehe Release Notes 1.0.0.

> ⚠️ Nutzung auf eigene Gefahr. CaseHUD ist ein privates Community-Projekt und steht in keiner Verbindung zu Lian Li.

### English

**Changes**
- **Lighting presets:** ready-made combinations of an effect and its parameters come from the community library or can be saved and re-applied yourself. Also via API v1: `GET` and `POST /api/v1/lighting/presets`, `POST /api/v1/lighting/presets/{id}/apply`, `DELETE /api/v1/lighting/presets/{id}`; the lighting status carries a `preset` field (details in `docs/API.md`)
- **Fresh install without personal defaults:** no built-in presets or templates that belong to one specific PC any more. New displays start with CPU/GPU designs that need no coolant or pump sensor. Existing settings are unchanged
- **Boot picture for the Universal Screen 8.8":** the CaseHUD logo is written once as the boot picture, tied to the start image switch (Settings → Devices). The disclaimer (now version 3) must be accepted once more. A forced rewrite skips an unchanged 8.8" boot picture
- **Scenes** keep the display's own rotation
- **Interface:** the dark/light switch always takes effect; saves for one display go out in order (two quick clicks could end on the first state); all design kinds have names in the interface; smaller fixes
- **More robust:** failures while writing the boot picture and while loading the preset file are handled more safely
- **Quality:** static analysis and more checks in CI, updated dependencies, built with Go 1.27.3

**Installation**
Download and run `CaseHUD-Setup-1.0.3.exe`; an existing installation is updated and keeps its settings. A portable ZIP is available too, and the update can also be installed from within CaseHUD. For permanent device writes and the disclaimer see the 1.0.0 release notes.

> ⚠️ Use at your own risk. CaseHUD is a private community project and is not affiliated with Lian Li.
