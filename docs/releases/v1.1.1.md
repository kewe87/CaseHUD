## CaseHUD 1.1.1

Beleuchtung pro Gerät ausschalten, Startlogo auf den Lüftern nur noch auf Wunsch, kein dauerhaftes Startbild mehr auf dem 8.8" und kleinere Korrekturen.
*Turn lighting off per device, fan start logo only on request, no more permanent boot picture on the 8.8" and smaller fixes. English below.*

### Änderungen
- **Beleuchtung pro Gerät aus:** Jedes Gerät hat im Tab „Beleuchtung“ einen eigenen Aus-Schalter. Ringe halten dabei Schwarz, TL-Lüfter bekommen ihr Aus-Signal, und im Mainboard-Sync-Modus wird der Aus-Zustand nach jeder Übernahme einmal neu gesetzt. Schreibvorgänge sind begrenzt und warten auf die Zustimmung zur Gerätesteuerung; braucht „Aus“ die Freigabe „Controller-Beleuchtung erlauben“, steht ein Hinweis im Tab
- **Ringe früher übernommen:** Der Sensordienst setzt einen gespeicherten Startzustand der Ringe schon beim Windows-Start, bevor die Oberfläche läuft. Die Firmware-Version der Ringe wird angezeigt
- **Hinweis „Gerät erkannt“:** Neu erkannte Geräte werden in der Beleuchtung gemeldet
- **Startlogo auf den Lüftern nur auf Wunsch:** Das Schreiben des Startlogos auf die TL-LCD-Lüfter ist jetzt standardmäßig aus und lässt sich in den Einstellungen einschalten. Bestehende Installationen schreiben ab diesem Update ebenfalls nicht mehr, bis die Option angehakt wird
- **Kein Startbild mehr auf dem 8.8":** Das 8.8"-Display zeigt beim Einschalten ohnehin immer sein eigenes Logo; CaseHUD schreibt deshalb kein Startbild mehr in das Gerät. Das Bild beim Beenden von CaseHUD bleibt erhalten. Haftungsausschluss und Dokumentation sind entsprechend angepasst
- **Kopfzeile:** Der Status erscheint nur noch bei Problemen, bei schmalen Fenstern zeigen die Tabs nur Symbole, nichts überlappt mehr
- **Gehäuse-Skizze:** Große Teile wie Mainboard oder Verteilerplatte werden zuerst gezeichnet, darauf montierte Teile bleiben sichtbar

### Installation
`CaseHUD-Setup-1.1.1.exe` herunterladen und ausführen; eine bestehende Installation wird aktualisiert, Einstellungen bleiben erhalten. Alternativ gibt's eine portable ZIP; das Update direkt aus CaseHUD ist ebenfalls möglich. Hinweise zu dauerhaften Schreibvorgängen im Gerät und zum Haftungsausschluss: siehe Release Notes 1.0.0.

> ⚠️ Nutzung auf eigene Gefahr. CaseHUD ist ein privates Community-Projekt und steht in keiner Verbindung zu Lian Li.

### English

**Changes**
- **Lighting off per device:** every device has its own off switch in the lighting tab. Rings hold black, TL fans get their off signal, and in motherboard-sync mode the off state is set again once after every takeover. Writes are bounded and wait for the device control consent; when "Off" needs "allow controller lighting", the tab shows a note
- **Rings taken over earlier:** the sensor service applies a stored ring start state already at Windows start, before the interface runs. The ring firmware version is shown
- **"Device detected" hint:** newly detected devices are reported in the lighting tab
- **Fan start logo only on request:** writing the start logo to the TL LCD fans is now off by default and can be switched on in the settings. Existing installations also stop writing it with this update until the option is ticked
- **No more boot picture on the 8.8":** the 8.8" display always shows its own logo at power-on anyway, so CaseHUD no longer writes a boot picture to the device. The picture shown when CaseHUD exits stays. Disclaimer and documentation are updated accordingly
- **Header:** the status only appears on problems, tabs show icons only in narrow windows, nothing overlaps any more
- **Case sketch:** large parts such as the motherboard or distribution plate are drawn first, so parts mounted on them stay visible

**Installation**
Download and run `CaseHUD-Setup-1.1.1.exe`; an existing installation is updated and keeps its settings. A portable ZIP is available too, and the update can also be installed from within CaseHUD. For permanent device writes and the disclaimer see the 1.0.0 release notes.

> ⚠️ Use at your own risk. CaseHUD is a private community project and is not affiliated with Lian Li.
