## CaseHUD 1.0.2

Selbst-Update mit signierter Prüfung.
*Self-update with signature check. English below.*

### Änderungen
- **Update direkt aus CaseHUD:** Meldet CaseHUD eine neue Version, zeigt das Banner die Release Notes und „Jetzt installieren“. CaseHUD lädt `SHA256SUMS.txt` und dessen Signatur von GitHub, prüft die Signatur mit dem eingebauten Schlüssel und danach den Hash des Setups, und startet das Setup erst dann. Windows fragt nach Administratorrechten; danach startet CaseHUD wieder, der Autostart bleibt wie eingestellt. Installiert wird nur auf Klick, nie automatisch. Die portable ZIP aktualisiert sich nicht selbst
- **API v1:** `GET /api/v1/update`, `POST /api/v1/update/check` und `POST /api/v1/update/install`, damit andere Programme ein Update anzeigen und anstoßen können (Details in `docs/API.md`)
- **`CaseHUD.exe --quit`** beendet ein laufendes CaseHUD sauber; das Setup nutzt das statt eines harten Beendens
- Die Library heißt jetzt `CaseHUD-Library` (die alte Adresse funktioniert weiter)
- Tests: stabilere Zeittests auf langsamen CI-Rechnern; der Library-Test findet die echte Library wieder

### Installation
`CaseHUD-Setup-1.0.2.exe` herunterladen und ausführen; eine bestehende Installation wird aktualisiert, Einstellungen bleiben erhalten. Ab dieser Version geht das nächste Update direkt aus CaseHUD. Alternativ gibt's eine portable ZIP. Hinweise zu dauerhaften Schreibvorgängen im Gerät und zum Haftungsausschluss: siehe Release Notes 1.0.0.

> ⚠️ Nutzung auf eigene Gefahr. CaseHUD ist ein privates Community-Projekt und steht in keiner Verbindung zu Lian Li.

### English

**Changes**
- **Update from within CaseHUD:** when CaseHUD reports a new version, the banner shows the release notes and "Install now". CaseHUD downloads `SHA256SUMS.txt` and its signature from GitHub, verifies the signature with the built-in key and then the setup's hash, and only then starts the setup. Windows asks for administrator rights; CaseHUD starts again afterwards and autostart stays as it was. Updates are installed on click only, never automatically. The portable ZIP does not update itself
- **API v1:** `GET /api/v1/update`, `POST /api/v1/update/check` and `POST /api/v1/update/install`, so other programs can show and start an update (details in `docs/API.md`)
- **`CaseHUD.exe --quit`** closes a running CaseHUD cleanly; the setup uses it instead of ending it hard
- The library is now called `CaseHUD-Library` (the old address keeps working)
- Tests: steadier timing tests on slow CI machines; the library test finds the real library again

**Installation**
Download and run `CaseHUD-Setup-1.0.2.exe`; an existing installation is updated and keeps its settings. From this version on, the next update can be installed from within CaseHUD. A portable ZIP is available too. For permanent device writes and the disclaimer see the 1.0.0 release notes.

> ⚠️ Use at your own risk. CaseHUD is a private community project and is not affiliated with Lian Li.
