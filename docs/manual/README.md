## Conventions

- **Bold** marks labels from the interface (tabs, switches, fields).
- **Tab → Group → Entry** describes a path through the interface, e.g. **Settings → Areas**.
- Instructions are numbered steps.

## Help from the program

The program links to individual sections of this manual. The mapping of interface areas to page and section is in [links.json](../handbuch/links.json); the section headings are fixed for that and must not be renamed.
