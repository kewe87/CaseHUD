## Schreibweise

- **Fett** sind Bezeichnungen aus der Oberfläche (Reiter, Schalter, Felder).
- **Reiter → Gruppe → Eintrag** beschreibt einen Weg durch die Oberfläche, z. B. **Einstellungen → Bereiche**.
- Anleitungen sind nummerierte Schritte.

## Hilfe aus dem Programm

Das Programm verweist auf einzelne Abschnitte dieses Handbuchs. Die Zuordnung von Bereichen der Oberfläche zu Seite und Abschnitt steht in [links.json](links.json); die Abschnittsüberschriften sind dafür fest und dürfen nicht umbenannt werden.
